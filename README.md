# AI_Chat_Bot

<img width="608" height="625" alt="image" src="https://github.com/user-attachments/assets/5a531918-2734-4b1c-a91d-124e9c505299" />


This project is an AI-powered chatbot application built using Python and Natural Language Processing (NLP) techniques. The chatbot is designed to understand user queries and respond intelligently based on predefined intents. It uses a TF-IDF vectorizer to convert user input into numerical form and compares it with trained patterns using cosine similarity to find the most relevant response. The backend is implemented using Flask, which handles API requests and returns chatbot responses, while an alternative interactive UI is built using Streamlit for real-time chat experience. The system loads trained models such as vectorizer, label encoder, and response mappings from serialized files, ensuring fast and efficient response generation. When a user sends a message, it is processed, vectorized, and matched against existing patterns to identify the best intent and return a suitable reply. To run the project, first train the model using the training script **(python model/train_model.py)**, then start the Flask server using **python app.py** or launch the Streamlit interface using **streamlit run app.py**. Once running, users can interact with the chatbot through a web interface and receive automated responses based on their queries.
